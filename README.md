## Hi, I'm Maksim 👋

I collect music by the album — 23,000+ tracks, FLAC rips, music videos, live sets — and build software for it.
Under the name **Grimsby** I make free offline apps for Windows that keep your library in order and good-looking.
I also write about hip-hop and albums in my Telegram channel **[@itsgrimsby](https://t.me/itsgrimsby)** (in Russian).
